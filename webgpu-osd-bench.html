osdDecode.wgsl real-GPU verification

Runs the OSD (ordered statistics decoding) GPU kernel (one workgroup per candidate: parallel selection-sort by |LLR|, sequential 91-step Gauss-Jordan elimination with a barrier-synchronized pivot search each step, matmul-based zero-flip + depth-flip hypothesis testing) against real WebGPU hardware and compares every output against osdDecode.ts's plain-TS reference (itself a direct port of lib/ft8mon/osd.cc). This is the first time this kernel touches an actual WGSL compiler/GPU driver — everything before this was JS-simulated only.
